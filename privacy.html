プライバシーポリシー

「数字厨-自動投稿」（以下「本ツール」）は、YouTubeチャンネル「数字厨」の運営者本人だけが、自分のチャンネルへ動画を投稿するために使う個人用ツールです。

取得する情報

運営者本人がGoogleアカウントの認証で許可した範囲で、YouTube Data API を通じて、動画のアップロード、タイトル・説明などの設定、公開状態の変更を行います。

情報の利用と共有

認証情報（トークン）は運営者本人のパソコン内にのみ保存し、第三者に提供・販売・公開しません。本ツールの利用者は運営者本人のみで、他の利用者の個人情報は取得しません。

YouTube API サービスについて

本ツールは YouTube API サービスを利用しています。YouTube 利用規約およびGoogle プライバシーポリシーが適用されます。

許可の取り消し

運営者は、Googleアカウントの「サードパーティのアクセス」からいつでも本ツールの許可を取り消せます。
